SIRET Form Filler

Page de démonstration de l'extension

Code source Confidentialité

Installez l'extension, puis faites un clic droit dans les champs ci-dessous. L'entrée « Générer un SIRET aléatoire » (ou SIREN) n'apparaît que sur les champs reconnus. La touche Menu et Maj+F10 fonctionnent aussi.

Chaque cas indique ce qui est attendu. Une fois un champ rempli, la ligne d'état vérifie la clé de contrôle et le journal à droite liste les événements reçus par la page, comme le ferait React, Angular ou Vue. Ctrl+Z annule le remplissage.
